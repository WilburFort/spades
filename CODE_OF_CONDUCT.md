# Code of Conduct

Spades Night is a friendly card table. We expect the same at the project.

- Be welcoming and patient. Many contributors will be new to open source, to JavaScript, or to Spades.
- Be respectful in disagreement. Argue about code and rules, never about people.
- No harassment, discrimination, or personal attacks, in issues, pull requests, or anywhere the project is discussed.
- Assume good intent, and ask before assuming the worst.

Maintainers may edit, hide, or remove comments and contributions that break these expectations, and may block repeat offenders. If something happens that you would rather not raise in public, open a private report by emailing the repository owner listed on the GitHub profile.

This document is adapted in spirit from the Contributor Covenant.
